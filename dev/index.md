# Ocsigen tutorial

Ocsigen is a framework for client/server Web and mobile applications in OCaml. This tutorial shows how to use it, from a first application to advanced features. If you do not know where to begin, read the [introduction](./intro.md).

To install Ocsigen, follow the [installation instructions](https://ocsigen.org/install). The opam package `ocsigen` installs the main libraries this tutorial uses.

The reference manuals and APIs of these libraries are in their own packages: `Eliom`, `Ocsigen Server`, `Ocsigen Start`, `Ocsigen Toolkit`, `Js_of_ocaml`, `TyXML` and `Lwt`.
